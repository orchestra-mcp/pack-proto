# orchestra-mcp/pack-proto

Protobuf and gRPC skills for Go-Rust communication

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-proto
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-proto")
```

## Contents

| Type | Names |
|------|-------|
| Skills | proto-grpc |
| Agents | quic-protocol |
| Hooks | None |

## Stacks

This pack is recommended for: **go, rust**
